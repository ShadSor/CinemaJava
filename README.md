# CinemaJava

Консольное приложение для кинотеатра: фильмы, залы, сеансы и продажа билетов.
Данные хранятся в памяти и пропадают при выходе из программы.

## Запуск

```
./gradlew run --console=plain
```

На Windows: `gradlew.bat run --console=plain`. Флаг `--console=plain` нужен, чтобы меню нормально читало ввод.

При старте загружаются демо-данные (несколько фильмов, залы, сеансы на завтра и пара билетов).
Чтобы начать с пустого кинотеатра: `./gradlew run --console=plain --args="--empty"`.

## Структура

- `domain.entity` — `Movie`, `Hall`, `Screening` (сеанс), `Ticket`, общий `AbstractEntity`
- `domain.exception` — `CinemaException`, `ValidationException`, `NotFoundException`
- `repository` — интерфейсы репозиториев, `repository.impl` — InMemory-реализации
- `service` — `CinemaService` с бизнес-правилами
- `ui` — консольный интерфейс; `ui.command` — команды меню (паттерн «Команда»), `ui.Menu` — вызывающая сторона

## Правила

- Сеанс нельзя назначить в прошлом или поверх другого сеанса в том же зале.
- Билет нельзя продать на занятое место, на начавшийся сеанс или покупателю младше возрастного ограничения фильма.
- Фильм, зал или сеанс нельзя удалить, пока с ними связаны сеансы или проданные билеты.
